Clínica Ikigai · saúde integrativa com agendamento por chatbot de IA

Dados operacionais reais calculados a partir dos agendamentos no banco de dados da clínica; respostas da pesquisa são registradas neste navegador. Cada indicador informa sua fonte. As variações comparam com o período anterior de mesmo tamanho.

Visão macro: 8 painéis

Como ler: cada painel reúne indicadores com peso. A nota do painel vai de 0 a 100 (indicador verde vale 100, amarelo 50 e vermelho 0, multiplicado pelo peso). Painel verde: nota de 75 ou mais. Amarelo: de 30 a 74. Vermelho: abaixo de 30. Um painel nunca fica verde se tiver indicador vermelho. Clique em um painel para ver só os indicadores dele. As metas são provisórias; a tabela completa está no fim da página.
